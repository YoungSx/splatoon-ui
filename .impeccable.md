# Splatoon UI — Design Context

## Users

- **Primary**: Frontend developers building Splatoon fan sites, game portals, or Nintendo-themed projects
- **Secondary**: Splatoon community creators (fan artists, wikis, tournament organizers)
- **Context**: Developers installing via npm/registry, customizing tokens, composing pages from components
- **Job to be done**: Get a visually distinctive, Splatoon-authentic component library running quickly without designing from scratch
- **Emotion**: Excitement, creative energy, "this looks like the real game site"

## Brand Personality

- **3 words**: Chaotic, Street Punk, Sun-scorched
- **Voice**: Loud, irreverent, high-energy — like a Splatoon Splatfest announcement
- **Anti-references**: Corporate dashboards, Material Design, Apple HIG, any "clean & minimal" UI
- **References**: splatoon.nintendo.com, street art, punk zines, skate deck graphics, 90s rave flyers

## Aesthetic Direction

- **Visual tone**: Anti-minimalist scrapbook — overlapping layers, torn paper, tape, stickers, ink splatters
- **Typography**: Skewed bold uppercase headings (street graffiti feel), clean readable body text
- **Color**: Neon yellow (#E3FF00) + Ink blue (#4100FF) as brand collision, desert sand (#EAD6B8) as surface, chaos black (#181818) as text
- **Layout**: Broken grid, intentional asymmetry, elements overlapping on Z-axis
- **Motion**: Bouncy spring entrances, parallax depth, micro-interactions on hover — but always respecting reduced-motion
- **Theme**: Dual — Light (desert wasteland Splatsville) + Dark (night battle ink)

## Design Principles

1. **Chaos with intent** — Every "messy" element is deliberately placed. Asymmetry is a choice, not an accident.
2. **Texture over flatness** — Surfaces should feel tactile: torn edges, tape strips, ink stains, paper grain. No smooth gradients.
3. **Break the box** — Elements should escape their containers. Characters break frame, shadows are solid and offset, borders are clipped and skewed.
4. **Energy through motion** — Bouncy, spring-based animations. Nothing linear. Elements arrive with personality, not efficiency.
5. **Accessible chaos** — All the wild visuals must respect reduced-motion, maintain WCAG AA contrast, and work with screen readers. The chaos is visual, not functional.

## Component Strategy (Progressive)

### Phase 1 — Core Components (Splatoon-styled)
- Button (tape/sticker with clip-path)
- Card (torn paper edges, solid drop-shadow)
- Badge (sticker aesthetic)
- Input / Textarea (torn-edge borders)
- Dialog / Sheet (scrapbook overlay)
- Tabs (skewed tab buttons)
- Alert (tape-banded notice)

### Phase 2 — Decorative Elements
- Ink splatter backgrounds
- Marquee tape (infinite scroll text strip)
- Sticker decorative component
- Torn paper divider

### Phase 3 — Advanced
- Parallax scroll container
- Reduced motion toggle (global)
- Theme switcher (light/dark)
