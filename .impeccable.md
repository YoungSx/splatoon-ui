# Splatoon UI — Design Context

## Users

- **Primary**: Frontend developers building Splatoon fan sites, game portals, or Nintendo-themed projects
- **Secondary**: Splatoon community creators (fan artists, wikis, tournament organizers)
- **Context**: Developers installing via npm/registry, customizing tokens, composing pages from components
- **Job to be done**: Get a visually distinctive, Splatoon-authentic component library running quickly without designing from scratch
- **Emotion**: Excitement, creative energy, "this looks like the real game site"

## Brand Personality

- **3 words**: Chaotic, Street Punk, Sun-scorched
- **Voice**: Loud, irreverent, high-energy — like a Splatoon Splatfest announcement
- **Anti-references**: Corporate dashboards, Material Design, Apple HIG, any "clean & minimal" UI
- **References**: splatoon.nintendo.com, street art, punk zines, skate deck graphics, 90s rave flyers

## Aesthetic Direction

- **Visual tone**: Anti-minimalist scrapbook — overlapping layers, torn paper, tape, stickers, ink splatters
- **Typography**: Skewed bold uppercase headings (fooregular, obviously-narrow), clean readable body (Montserrat)
- **Color**: Neon Yellow (#EAFF3D) + Ink Blue (#603BFF) as brand collision, Desert Sand (#F5F0E8) as surface, Chaos Black (#0D0D0D) as text
- **Layout**: Broken grid, intentional asymmetry, elements overlapping on Z-axis
- **Motion**: Bouncy spring entrances, parallax depth, micro-interactions on hover — always respecting reduced-motion
- **Shadows**: Solid hard-offset shadows (`shadow-solid` system) over soft blurs

## Design Principles

1. **Chaos with intent** — Every "messy" element is deliberately placed. Asymmetry is a choice, not an accident.
2. **Texture over flatness** — Surfaces should feel tactile: torn edges, tape strips, ink stains, paper grain. No smooth gradients.
3. **Break the box** — Elements should escape their containers. Characters break frame, shadows are solid and offset, borders are clipped and skewed.
4. **Energy through motion** — Bouncy, spring-based animations. Nothing linear. Elements arrive with personality, not efficiency.
5. **Accessible chaos** — All the wild visuals must respect reduced-motion, maintain WCAG AA contrast, and work with screen readers. The chaos is visual, not functional.

## Component Inventory (Implemented)

### Core
- **Button** — CVA variants (yellow/blue/green/orange/purple/destructive), drip clip-path animation, morph blob close button
- **Card** — Polaroid news card (3-layer torn-paper + staples + tape), hanging tag card, styled photo
- **Tabs** — Skewed parallellogram tabs with double-skew correction
- **Dialog** — shadcn-based with morph blob close button
- **Splatoon Modal** — CSS custom property-driven state (--alpha, --scale, --duration), backdrop, stagger content
- **Input / Select / Checkbox / Radio** — shadcn-styled form controls
- **Badge / Alert** — Sticker aesthetic variants

### Decorative
- **Tape Title** — Red/yellow/black background with SVG tape pseudo-elements
- **Banner Divider** — Wavy section transitions
- **Marquee** — Infinite scroll text strip (tape variant)
- **Ink Splat Components** — 12 inline SVG splat variants + interactive spawner
- **Stickers** — Decorative sticker components
- **Background Patterns** — 13 camo/pattern utility classes with retina support

### Advanced
- **Navigation** — Sticky header with scroll-driven shrinking, full-screen overlay menu with JS-driven polar-interpolated clip-path animation
- **Trailer Video** — YouTube modal with ink splash canvas (WebGL), responsive tape decorations
- **Ink Splash Canvas** — WebGL shader-driven ink transition effect
- **Card Stack Carousel** — Physics-based pendulum model with impulse-driven state
- **Gallery System** — Unified carousel with squid-icon pagination
- **InView** — IntersectionObserver scroll-triggered animation system
- **Page Transition** — WebGL ink splash page transitions
- **Character Showcase** — 3D character display with ink effects

## Tech Stack

- **Framework**: Next.js 16 (Turbopack)
- **Styling**: Tailwind CSS v4 (`@theme inline` in CSS, no config file)
- **Component Base**: shadcn/ui + Radix UI primitives
- **Animation**: CSS transitions + keyframes, requestAnimationFrame for complex physics
- **WebGL**: Custom ink splash shaders (canvas-based)
- **Build**: pnpm, TypeScript strict mode

