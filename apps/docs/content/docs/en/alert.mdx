## Usage

Use Alert for compact messages that should stay in the page flow. The title and description primitives preserve a readable hierarchy.

## Design Notes

- Use the destructive variant only for irreversible or blocking states.
- Keep alert copy direct and short.
- Prefer Dialog when the user must make a decision.
