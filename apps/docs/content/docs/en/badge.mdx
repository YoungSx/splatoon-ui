## Usage

Use Badge for short status labels and category markers. It is intentionally compact, so it works inside cards, toolbars, and dense docs tables.

## Design Notes

- Keep badge copy to one or two words.
- Use color to group information, not to encode the only meaning.
- Pair badges with visible text when the status is important.
