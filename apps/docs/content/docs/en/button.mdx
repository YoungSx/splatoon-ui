## Usage

Use Button for primary commands, navigation actions, and compact calls to action. The component keeps the Splatoon UI motion and color treatment while preserving native button and anchor behavior.

## Design Notes

- Use one primary color per action group.
- Prefer `variant="ghost"` only when the surrounding surface already carries enough emphasis.
- Keep labels short enough to survive the drip animation without resizing the layout.
