## Usage

Use Carousel when the consumer needs to own slide content and controls. The root manages index state, while viewport, content, item, swipe, and pagination primitives keep layout concerns explicit.

## Design Notes

- Prefer controlled `index` when the carousel is connected to other UI.
- Keep high-level gallery presets internal until their data model is stable.
- Compose custom controls with `useCarousel` instead of passing button slots into the root.
