## Usage

Use Checkbox for independent yes/no settings. It works best when the label describes exactly what toggles.

## Design Notes

- Avoid using checkbox for mutually exclusive choices.
- Keep the hit target generous.
- Use a disabled state only when the reason is visible nearby.
