## Usage

Use Dialog for blocking decisions and focused content. Compose the trigger, content, header, title, and description to keep accessibility semantics explicit.

## Design Notes

- Keep the title concrete and action-oriented.
- Use Dialog for tasks that need focus containment.
- Prefer Sheet or Popover for lighter contextual surfaces.
