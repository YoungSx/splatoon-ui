## Usage

Use Input with Label for named text fields. Keep validation and helper text near the field so repeated form workflows stay scannable.

## Design Notes

- Always pair inputs with labels.
- Reserve placeholder text for examples, not field names.
- Keep field width tied to the expected input length.
