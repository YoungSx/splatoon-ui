## Usage

Use Tabs to switch between related views without leaving the current page. The trigger and panel primitives keep keyboard and pointer behavior aligned.

## Design Notes

- Keep tab labels short.
- Use the line variant for dense pages.
- Use the trapezoid variant when the tabs are the primary navigation element.
