## Usage

Use Tape and Staple inside a relative container to pin decorative assets over cards, images, and editorial panels.

## Design Notes

- The root is absolutely positioned and pointer-events are disabled.
- Prefer preset positions for common card corners, then use `className` for bespoke placement.
