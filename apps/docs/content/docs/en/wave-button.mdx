## Usage

Use WaveButton for compact graphical actions such as close controls, menu-style triggers, and small custom glyph commands. The component owns the blob shell and does not render text children; pass `icon` when the default line glyph is not the right graphic.

## Design Notes

- Always provide an accessible label with `aria-label`.
- Use `icon` for a custom graphic node, or `icon={null}` when the blob shape itself is the affordance.
- Use `animation="none"` when the surrounding surface already has strong motion.
