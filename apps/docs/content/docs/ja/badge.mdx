## 使い方

`Badge` は『スプラトゥーン3』の公式実機ビジュアルスタイルを忠実に再現します：

- **破れ紙バッジ（デフォルト）**：公式インクカラー6色（yellow, blue, green, red, purple, monochrome）に対応した、ギザギザした破れ紙の質感を持つステータスラベルです。
- **ピン / ネームプレートバッジ（Pin / Splashtag）**：ゲーム内のネームプレート（Splashtag）右下に装着される金属ピンバッジを再現。1:1正方形、透明背景、金銀銅（gold, silver, bronze）の金属光沢とベベルを備えます。内蔵プリセット（`judd` ジャッジくん、`cohozuna` ヨコヅナ、`steelhead` バクダン、`big-run` ビッグラン、`splattershot` スプラシューター）や `src` によるカスタム画像指定に対応します。
- **通知ドット / 感嘆符バブル（Dot / Exclamation）**：ロビー端末（Lobby Terminal）の報酬通知やコジャケの宝探しアラートを再現した、鮮やかなインク感嘆符（`!`）吹き出しです。子要素をラップすることで四隅への角標配置にも対応します。

## デザインメモ

- **文字量**：テキストラベルは1〜2語に抑え、スプラトゥーンらしい力強いストリート感を保ちます。
- **金属バッジ**：ネームプレートバッジは1:1正方形、透明背景、実機準拠の金属光沢レイヤーで構成されています。
- **角標配置**：`dot` を指定して子要素をラップすると、デフォルトで右上に自動配置されます（`placement="top-right"`）。
