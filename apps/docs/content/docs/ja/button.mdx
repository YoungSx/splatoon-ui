## 使い方

Button は主要コマンド、ナビゲーション操作、コンパクトな CTA に使います。Splatoon UI の動きと色を保ちながら、button と anchor の自然な挙動を維持します。

## デザインメモ

- 1 つの操作グループには 1 つの強調色を使います。
- 周囲の面が十分に強い場合だけ `variant="ghost"` を使います。
- drip アニメーションでレイアウトが広がらない短いラベルにします。
