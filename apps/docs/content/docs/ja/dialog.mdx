## 使い方

Dialog はブロックする判断や集中コンテンツに使います。trigger、content、header、title、description を組み合わせ、明確なアクセシビリティ構造にします。

## デザインメモ

- タイトルは具体的で行動につながる内容にします。
- フォーカスを閉じ込める必要がある時に使います。
- 軽い文脈表示には Sheet や Popover を優先します。
