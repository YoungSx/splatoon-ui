## 使い方

Input は Label と一緒に使います。検証や補助文はフィールドの近くに置き、反復するフォーム作業を読み取りやすくします。

## デザインメモ

- 入力には必ずラベルを付けます。
- placeholder は例に使い、フィールド名には使いません。
- 幅は想定する入力長に合わせます。
