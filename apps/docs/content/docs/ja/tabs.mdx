## 使い方

Tabs は現在のページを離れず、関連ビューを切り替える時に使います。trigger と panel primitives はキーボードとポインター挙動を揃えます。

## デザインメモ

- タブラベルは短くします。
- 密度の高いページには line バリアントを使います。
- 主要ナビゲーションの場合は trapezoid バリアントを使います。
