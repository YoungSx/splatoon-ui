## 使い方

TapeTitle は compact label や feature title に tape-backed heading が必要な場合に使います。

## 設計メモ

- Tape ends が固定の bleed space を取るため、copy は短く保ちます。
- `color="black"` は最も強い contrast、red と yellow は accent に向きます。
