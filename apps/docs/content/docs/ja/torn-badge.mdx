## 使い方

TornBadge は高レベルの Badge wrapper ではなく、生の torn-paper badge が必要な場合に使います。

## 設計メモ

- ラベルは短く保ちます。
- ライブラリ標準の badge 抽象が必要なら Badge を使います。
