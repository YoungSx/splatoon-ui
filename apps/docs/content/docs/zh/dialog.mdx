## 用法

Dialog 适合阻断式决策和聚焦内容。组合 trigger、content、header、title 和 description 可以保持明确的可访问语义。

## 设计备注

- 标题要具体并指向动作。
- 需要焦点约束时使用 Dialog。
- 更轻的上下文内容优先使用 Sheet 或 Popover。
