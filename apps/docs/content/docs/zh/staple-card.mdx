## 用法

当卡片明确需要订书钉信息流纸面时使用 StapleCard。请从 `splatoon-ui/staple-card` 导入，不要通过通用 Card 变体绕一层。

## 设计备注

- 使用 `variant` 选择订书钉和胶带预设。
- 使用 `surface` 切换白色或深色纸面。
- 需要自定义操作区或内容布局时，配合 `StapleCardTitle` 和 `StapleCardDescription` 使用 children。
