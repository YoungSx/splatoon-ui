# Credits

Splatoon UI is a fan-made React component library. This file lists all third-party
resources, tools, and references used in the project.

---

## Visual Design Reference

- **splatoon.nintendo.com** — primary design source; all UI tokens, layouts, animations,
  and component patterns are reverse-engineered from the official Splatoon web presence.
- **nintendo.com/hk/switch/av5ja/coop/** — Salmon Run sub-site; additional color tokens
  (`--color-salmon-run-*`) and palette references.
